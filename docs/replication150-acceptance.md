# 150-paper acceptance language

## Pass means

A paper is a full runnable pass only when marker, protocol, compile, open, Autopilot ×3, and four-file packs all succeed, and required materials are ready.

## Claim limits

- Autopilot results are **pipeline sanity** only.
- Autopilot is **not human effect reproduction**.
- Blocked/gated/missing materials are never counted as runnable passes.
- Framework-only markers are not lab success.

## Status buckets

- `smoke_pass` / `pilot_pass`
- `adaptation` (known deviations logged)
- `framework_only`
- `blocked`
- `excluded` / `replace`
- `failed`
